# LongVideo AI – APK updates

This public repository is reserved for distributing LongVideo AI Android application updates.

- The application source code remains in the private `longtb2-coder/lamtruyen` repository.
- Only signed APK releases and public update metadata should be published here.
- Do not upload source code, signing keystores, passwords, API keys, or other secrets.

Update delivery is not active yet. A stable Android signing key and an automated release upload from the private source repository must be configured before in-app updates can safely install over an existing app.
